# Heller-Einstein

**Purpose:** Third co-foundational repository beside Heller-Godel and Heller-Dirac, hosting the framework's gravitational, interface-typed, and projection-induced-stochasticity content via the Einstein-Heller Interface Program.

Where Heller-Godel hosts the proof-theoretic core and Heller-Dirac hosts the spectral / Hopf / modular / field-theoretic apparatus, Heller-Einstein hosts:

1. Typed interface ontology: bulk dynamics, observer-relative trace maps, semantic lifts, reconstruction maps, and compatible latent fibers.
2. Projection-induced stochasticity: deterministic latent evolution observed through many-to-one trace maps induces observer-level Markov kernels that are generically stochastic.
3. Conservative Einstein-Cartan-Dirac physical core: minimal gravity + Dirac matter + scalar projection field + pseudoscalar coherence field + observer-interface boundary term.
4. Sufficiency hierarchy: microstate sufficiency, semantic sufficiency, task sufficiency, and semantic holography.
5. Placeholder spaces: typed slots `X_15 -> X_7 -> X_3 -> X_2`, not topology commitments.

## Architectural role

Heller-Einstein is co-foundational with Heller-Godel and Heller-Dirac:

- Heller-Godel hosts proof-theoretic core, PFK, claim-grade discipline, and Universal Bridge specs.
- Heller-Dirac hosts spectral / Hopf / modular / field-theoretic apparatus.
- Heller-Einstein hosts gravity / interface / projection scaffold.

Heller-Einstein consumes Heller-Godel for PFK substrate, framework objects, and claim-grade discipline. It publishes `HE-*` objects for downstream consumption when content needs typed-interface or projection-induced-stochasticity apparatus.

Heller-Einstein depends on Heller-Dirac after `HE-PROJ-001`, using the dual-upstream pattern established in `yang-mills` and `bsd-proof-program`. The Heller-Dirac citation is structural-cognate only; it does not transfer proof.
