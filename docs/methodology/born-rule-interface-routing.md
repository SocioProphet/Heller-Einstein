## Relationship to Born weights

A Markov kernel from `HE-PROJ-001` has the form:

```text
K(y, y') = mu_y({x in F_y : tau(f(x)) = y'})
```

A Born probability has the form:

```text
P(m) = Tr(E_m rho)
```

These are both probability assignments, but they are not the same structure by default. The first is an interface-induced trace kernel. The second is a positive Hilbert-space state/effect pairing.

A future bridge may compare them only if it supplies:

1. a typed trace map from latent or field-theoretic states to measurement outcomes;
2. a positive Hilbert-space or algebraic state space;
3. effects/projections corresponding to measurement events;
4. a proof that the induced kernel equals the Born state/effect pairing, not merely an arbitrary stochastic kernel;
5. non-claim language preserving the difference between interface stochasticity and quantum measurement theory.

Without those ingredients, Heller-Einstein can at most say that stochastic observer-level laws may arise from projection loss.
