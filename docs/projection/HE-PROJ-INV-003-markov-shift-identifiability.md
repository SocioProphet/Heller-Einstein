## Problem

`HE-PROJ-INV-001` proved that every countable Markov kernel admits some deterministic latent realization. Its skew-product construction is sufficient for existence but not canonical: it contains internal padding and admits many fiberwise rearrangements that induce the same kernel.

`HE-PROJ-INV-003` identifies the canonical realization in the finite stationary case and proves uniqueness in the natural observer-generated invertible class.

## Finite setting

Let `Y` be a finite set and let `K : Y x Y -> [0,1]` be a Markov kernel.

Choose a stationary probability law `pi` on `Y`:

```text
pi K = pi
```

For finite `Y`, at least one stationary probability law exists. If the chain has multiple closed communicating classes, the choice of `pi` is part of the realization data.

## Canonical realization — two-sided Markov shift

Define:

```text
X_K := Y^Z
```

with left shift:

```text
(T omega)_n = omega_{n+1}
```

and trace map:

```text
tau(omega) = omega_0
```

Let `mu_{pi,K}` be the two-sided stationary Markov measure determined by:

```text
P(omega_0 = y_0) = pi(y_0)
P(omega_{n+1} = y' | omega_n = y) = K(y,y')
```

for all `n in Z`.

The finite-dimensional cylinder probabilities are:

```text
mu([y_m, ..., y_n]) = pi(y_m) K(y_m,y_{m+1}) ... K(y_{n-1},y_n)
```

after shifting indices so the left boundary marginal is stationary. Consistency follows from `pi K = pi` and the row-stochastic condition. Existence and uniqueness of the product measure follow from Kolmogorov extension.

## Proposition 1 — Canonical realization induces K

The quadruple:

```text
(X_K, T, tau, {mu_y})
```

where `mu_y` is the conditional measure `mu_{pi,K}( . | omega_0 = y)`, induces the kernel `K` under `HE-PROJ-001`.

### Proof

For `y,y' in Y`:

```text
K_ind(y,y') = mu_y({omega : tau(T omega) = y'})
```

But:

```text
tau(T omega) = (T omega)_0 = omega_1
```

so:

```text
K_ind(y,y') = P(omega_1 = y' | omega_0 = y) = K(y,y')
```

by the defining Markov property. Therefore the induced kernel is exactly `K`.

## Definition — observer-generated realization

A realization `(X, f, tau, mu)` of `K` is observer-generated if the smallest `f`-invariant sigma-algebra containing all trace coordinates:

```text
tau o f^n,  n in Z
```

is the whole measurable structure of `X`, modulo `mu`-null sets.

Equivalently: the bi-infinite trace history separates points almost everywhere. There is no hidden bulk factor invisible to the observer across all time.

## Theorem 2 — Identifiability of the two-sided Markov shift

Let `(X, f, tau, mu)` be a realization of finite kernel `K` with stationary law `pi`, satisfying:

1. `f` is invertible mod null;
2. `f` preserves `mu`;
3. the trace process `tau(f^n x)` is stationary with marginal `pi` and transition kernel `K`;
4. the realization is observer-generated.

Then `(X, f, tau, mu)` is measure-theoretically isomorphic to the two-sided Markov shift `(Y^Z, T, tau_0, mu_{pi,K})`.

More explicitly, the coding map:

```text
C : X -> Y^Z
C(x)_n = tau(f^n x)
```

is an isomorphism mod null, satisfies:

```text
C o f = T o C
```

and:

```text
tau_0 o C = tau
```

where `tau_0(omega)=omega_0`.

## Proof

The coding map `C` is measurable by construction.

It intertwines dynamics:

```text
(C(fx))_n = tau(f^n(fx)) = tau(f^{n+1}x) = (T C(x))_n
```

so `C o f = T o C`.

It also preserves trace:

```text
tau_0(C(x)) = C(x)_0 = tau(x)
```

The pushforward measure `C_* mu` is a shift-invariant measure on `Y^Z` because `f` preserves `mu` and `C` intertwines `f` with `T`.

By stationarity and the Markov transition hypothesis, every finite cylinder under `C_* mu` has probability:

```text
pi(y_m) K(y_m,y_{m+1}) ... K(y_{n-1},y_n)
```

which is exactly the defining cylinder probability of `mu_{pi,K}`. By uniqueness in Kolmogorov extension:

```text
C_* mu = mu_{pi,K}
```

Observer-generation says the sigma-algebra generated by all trace coordinates `tau o f^n` is all of `X` mod null. Therefore `C` is injective modulo null sets and has a measurable inverse on its image. Since `C_* mu = mu_{pi,K}`, the image has full `mu_{pi,K}` measure.

Thus `C` is a measure-theoretic isomorphism mod null, intertwining dynamics and trace. This proves the theorem.

## Sharpness of hypotheses

Each hypothesis is load-bearing.

### Dropping observer-generation

The skew-product realization from `HE-PROJ-INV-001` realizes `K` but includes extra `[0,1)` structure invisible to the trace process. It is not observer-generated. It is therefore not unique in the sense of this theorem.

### Dropping invertibility

The one-sided Markov shift on `Y^N` realizes `K` but is not invertible. It is not isomorphic to the two-sided shift as a measure-preserving dynamical system.

### Dropping stationarity

A realization with a non-stationary initial law can induce the same transition kernel `K` at the one-step conditional level but produce a different path measure. Stationarity is required for a canonical two-sided invariant measure.

### Dropping measure preservation

Without measure preservation, the coding pushforward need not be shift invariant. The Markov transition law may hold locally while the path measure fails to be the stationary Markov measure.

## Relationship to HE-PROJ-INV-001

`HE-PROJ-INV-001` proves existence by skew-product realization. That construction is non-canonical.

`HE-PROJ-INV-003` gives the canonical realization for finite stationary kernels: the two-sided Markov shift.

The two results are compatible:

- `HE-PROJ-INV-001`: every kernel has some deterministic realization.
- `HE-PROJ-INV-003`: finite stationary kernels have a canonical observer-generated invertible realization unique up to isomorphism.

## Relationship to HE-PROJ-INV-002

`HE-PROJ-INV-002` remains reserved for finite minimality.

The Markov shift is canonical and invertible but usually infinite. The finite-minimality functional optimizes a different criterion: smallest finite latent state set, usually without requiring invertibility or observer-generation.

Thus `HE-PROJ-INV-002` and `HE-PROJ-INV-003` do not collide:

- INV-002 asks for smallest finite realization.
- INV-003 gives the canonical invertible stationary observer-generated realization.

## Fixture check — HE-EX-001

`HE-EX-001` has:

```text
Y = {+, -}
K = [[2/3, 1/3], [1/3, 2/3]]
```

The stationary law is:

```text
pi(+) = pi(-) = 1/2
```

The canonical realization is the two-sided Markov shift on:

```text
{+, -}^Z
```

with stationary Markov measure determined by `pi` and `K`.

The entropy rate is:

```text
h(K) = - sum_y pi(y) sum_{y'} K(y,y') log_2 K(y,y')
```

For this symmetric two-state chain:

```text
h(K) = - (2/3) log_2(2/3) - (1/3) log_2(1/3)
     ≈ 0.918295834 bits / step
```

The finite `Z_12` realization used by `HE-EX-001` is a useful fixture but not the canonical observer-generated invertible realization. It is also not finite-minimal, as shown in `HE-PROJ-INV-001`.

## Countable and non-stationary extensions

This document proves the finite case. Countable-state kernels with a stationary probability measure can be treated by the same Markov-extension logic under standard measurability hypotheses. Transient or null-recurrent kernels may require sigma-finite or non-stationary extensions.

Those cases are reserved for future work. They are not active claims in this PR.

## Boundaries

This document does not:

- solve finite minimality (`HE-PROJ-INV-002`);
- make the skew-product realization unique;
- prove identifiability without the four stated hypotheses;
- handle transient or null-recurrent countable-state kernels;
- derive quantum mechanics;
- derive the Born rule;
- prove physical substrate uniqueness;
- claim that the canonical Markov shift is the physical substrate.

It proves a measure-theoretic identifiability theorem for the canonical finite stationary observer-generated invertible realization.
